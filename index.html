Tarus Quote Generator Guide

This tool allows you to easily import data from Verax, customize line items, and generate flawless PDFs.

⬇ Import Verax PDF

  • Use this to pull data from a quote you previously exported from Verax.
  • It automatically maps the Quote #, Addresses, Ref Info, Meta Data, and ALL Line Items cleanly.
  • Note: The browser will automatically open your default folder (usually "Downloads") to select your recently downloaded Verax file.

⤺ Undo / ⤻ Redo Memory

  • The application constantly tracks your edits. If you accidentally delete a line, edit the wrong price, or wipe the form by mistake, simply hit Undo to revert the document exactly as it was.

+ Add Line & Table Controls

  • Click + Add Line to manually add a new row to the parts table.
  • Use the ↑ and ↓ buttons on the left to reorder lines.
  • Use the red × button to delete a line entirely.
  • The Line Totals and Grand Total will automatically calculate as you type the Qty and Price.

💾 Save / Load Draft

  • If you get interrupted, click Save Draft. This saves your exact current progress directly into your browser's local memory.
  • If you accidentally close the tab, just reopen the tool and click Load Draft to instantly restore your work.

Faded Watermarks & Empty Notes

  • Any field showing faded, grey italic text (e.g. "Enter Description...") is a placeholder. These placeholders will NOT appear on the final downloaded PDF.
  • If you leave the "Custom Notes" area blank, the PDF generator will automatically delete that space so you don't end up with massive empty white gaps.
